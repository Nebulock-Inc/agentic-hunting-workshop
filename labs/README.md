Work from the Markdown on GitHub: every code block has a copy button. The PDF is the same
handout for printing or reading offline; copying a block out of it also gives you the exact
text, but some PDF viewers (macOS Preview) drop a line's leading spaces when you copy.

Modules 1 and 2 are hands-on: you run the searches in Splunk and write the hunts with
`athf`. Modules 3 and 4 are demos on the presenter's screen; follow along in the
handout, no typing needed.

In searches, text in angle brackets is a placeholder for you to replace, e.g.
`ppid=<node's pid>`: swap the whole `<…>` for the value you found.

Each module also has its answer key (`*-answer-key.md`): the same text plus the
expected findings and model answers, for anyone who wants to check their work.
