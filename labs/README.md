# Lab handouts

One file per module, in class order. **Start with 01** and work down.

- [`01-manual-hunt.md`](01-manual-hunt.md) — **Module 1 — Hunt the Front Door by Hand (30 min, together)**
- [`02-search-your-history.md`](02-search-your-history.md) — **Module 2 — Search Your History (15 min, together)**
- [`03-research-agent-demo.md`](03-research-agent-demo.md) — **Module 3 — Watch the Research Agent (35 min, instructor demo)**
- [`04-assistant-runs-the-hunt-demo.md`](04-assistant-runs-the-hunt-demo.md) — **Module 4 — The Assistant Runs the Hunt (40 min, instructor demo)**
- [`MCP_SETUP.md`](MCP_SETUP.md) — take-home: connect an AI assistant to your own ATHF workspace, as in Module 4.

Modules 1 and 2 are hands-on: you run the searches in Splunk and write the hunts with
`athf`. Modules 3 and 4 are demos on the presenter's screen; follow along in the
handout, no typing needed.

In searches, text in angle brackets is a placeholder for you to replace, e.g.
`ppid=<node's pid>`: swap the whole `<…>` for the value you found.

Answer keys are posted here after the class. During the class, work from these.
